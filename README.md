# CineMatch – Movie Recommendation System 🎬

CineMatch is a personalized movie recommendation system that suggests movies based on users' interests and preferences using Machine Learning.

### Features
- User registration and login
- Movie search and genre filtering
- Personalized recommendations
- Content-Based Filtering
- Collaborative Filtering
- Movie ratings and reviews

### Technologies
- Python
- HTML, CSS, JavaScript
- Pandas, NumPy, Scikit-learn
- Flask / Django
- MySQL / SQLite

### Installation
```bash
git clone https://github.com/YOUR-USERNAME/CineMatch-Movie-Recommendation-System.git
cd CineMatch-Movie-Recommendation-System
pip install -r requirements.txt
```
